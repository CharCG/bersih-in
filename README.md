## Description

[Bersih.In]() is an AI-powered waste classification web app that instantly identifies waste categories through image classification to help users sort and dispose of waste correctly. By promoting correct waste disposal, the web app contributes to [SDG 12](https://sdgs.un.org/goals/goal12) (Responsible Consumption and Production).
